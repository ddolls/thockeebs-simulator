# ThocKeebs: Mechanical Keyboard Simulator & Tuning Studio ⌨️

Official 3D interactive mechanical keyboard tuning & assembly simulator by **ThocKeebs Studio** (Bandung, Indonesia).

## 🚀 Overview
- **3D Procedural Keyboard Assembly**: Case, PCB, 7-layer acoustic dampening, plates, stabilizers tuning (lube & wire balancing), switches, and keycaps.
- **Realistic Acoustic Audio Engine**: Physical Web Audio API synthesis generating true-to-life switch acoustics (Linear, Tactile, Clicky, Silent, Deep Thock) and plate acoustics.
- **Customer Career & Workshop Mode**: Fulfill custom customer commissions, diagnose rattles, tune stabilizers, and build mechanical keyboards to exact customer specs.
- **ASMR Sound Test Arena**: Interactive keypress testing with real physical keyboard input detection.

## 🛠️ Tech Stack
- **Three.js** (3D WebGL Rendering)
- **Web Audio API** (Procedural Acoustic Sound Synthesis)
- **Vite** (Build Tool & Dev Server)
- **Monochrome Minimalist UI/UX** (Official ThocKeebs Studio Design System)

## 📦 Deployment
Built to deploy seamlessly on [Vercel](https://vercel.com/) with native Vite presets.

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
